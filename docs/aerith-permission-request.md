## Original Request Draft

To: comet@aerith.net
Subject: Permission request for AstroGuide comet planning metadata and images

Hi Seiichi,

I'm Chris Hollander, the developer of AstroGuide, an iOS astronomy planning app:
https://astroguide.space

I would like to request permission to use selected data from your Aerith weekly
bright-comet pages in AstroGuide's hosted metadata. The intended use is to help
amateur astronomers notice timely comet brightness changes, plan observations,
and open the relevant Aerith page for more context.

Specifically, I would like permission to use:

- comet designation/name and Aerith detail-page URL
- current and next-week magnitude estimates from the weekly table
- small cached copies of selected weekly comet thumbnail/images as optional
  in-app thumbnail or hero imagery, with attribution and link back to Aerith

AstroGuide will continue to compute observer-specific visibility, altitude, and
timing independently. Aerith would be credited as the source for the weekly
brightness/media information, and the app would link users back to the relevant
Aerith page rather than republishing the surrounding page text. I would prefer
to cache any approved images through AstroGuide metadata instead of hotlinking,
both for app reliability and to avoid creating direct image traffic against your
site.

Please let me know if this usage is acceptable, if you prefer a specific
attribution format, or if there are limits you would like me to respect. I am
happy to keep images disabled until you explicitly approve that part.

Thanks for maintaining such a useful comet resource.

Clear skies,
Chris Hollander
https://astroguide.space
